ymir-js / Tutorials

Learn the core in 11 puzzles

Each puzzle is a small board and a goal. Change a line or two, press Run, and watch your code play out on the board. No setup, nothing to install.

    What next?

    Every game on the home page is built from these same calls. The custom ones (Hnefatafl, Sokoban, Tactics, Reversi, Bomberman, Invaders) write their own rules on the core: read their rules.ts in examples/.
