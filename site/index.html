Using it

Plain classes: read the state, call a method, draw it however you like.

import { ChessGame, GoGame, CheckersGame } from 'ymir-js';

const chess = new ChessGame();
chess.move('e4');
chess.getBestMove({ depth: 3 }); // { san: 'Nf6', ... }

const go = new GoGame({ size: 9 });
go.play('4|4');
go.getStatus(); // { state: 'playing' }

const checkers = CheckersGame.create('turkish');
checkers.getLegalMoves(); // [{ from, path, captured }, ...]
  • Rules you can trustTested against the official rules: perft for chess, FMJD and Turkish federation rules for checkers.
  • Any UINo rendering, no framework. The examples use Preact; use what you like.
  • Typed, zero dependenciesTypeScript, an ES module with types, nothing else installed.
  • Your own gamesThe tutorials cover the whole core. The custom games show where it goes.

Use the ymir-js library (npm install ymir-js) for the board and the rules.
Before writing code, read https://aykutkardas.github.io/ymir-js/llms.txt,
and https://aykutkardas.github.io/ymir-js/llms-full.txt for exact types.
Coordinates are "row|col" strings. Use the built-in game classes
(CheckersGame, ChessGame, GoGame, Match3Board) when they fit; for a new
game, build on Board and Item from the core, as the custom games do.

Good to know

  • CoordinatesStrings "row|col", from 0, row 0 at the top. Chess also takes "e4".
  • Validated movesplay and move throw on an illegal move; ask getLegalMoves() first.
  • StateGames report getStatus() and save with toJSON() / fromJSON().
  • Packagesymir-js re-exports @ymir-js/core, checkers, chess, go and match3.
