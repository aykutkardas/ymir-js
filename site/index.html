ymir-js

A TypeScript toolkit for board games. Checkers, chess, Go and match-3 come with their full rules, built on a small board core you can use for your own games.

npm install ymir-js

Games

Checkers

Turkish and International, against the computer

  • Mandatory and maximum capture, full capture chains, flying kings
  • CheckersGame with undo, save/load and FMJD / Turkish draw rules
  • PDN FEN and move notation for International
Play Source API

Chess

Against a built-in engine, or two players

  • Every rule: castling, en passant, promotion, mate, stalemate, draws
  • Move generation verified with perft (4.8M positions from the start)
  • FEN, SAN, UCI, PGN, and getBestMove({ depth })
Play Source API

Go

9×9, 13×13 or 19×19, with scoring

  • Groups, liberties, captures, suicide, simple ko and superko
  • Pass, resign, dead stones, area or territory scoring with komi
  • GTP coordinates, handicap setup, undo, save/load
Play Source API

Match 3

A 20-move puzzle with cascades

  • Swap, match, gravity, refill and chain reactions in one call
  • Every cascade step reported, ready to animate
  • Hints, automatic shuffle, seedable boards
Play Source API

Custom games

These aren't in the library. Each is an example app that writes its own rules on the core Board and Item, to show what you can build with it.

Viking chess: get the king to a corner

A taste of the API

import { ChessGame, GoGame, CheckersGame, Match3Board } from 'ymir-js';

const chess = new ChessGame();
chess.move('e4');
chess.getBestMove({ depth: 3 });   // e.g. { san: 'Nf6', from: 'g8', to: 'f6', ... }

const go = new GoGame({ size: 9 });
go.play('4|4');
go.getStatus();                    // { state: 'playing' }

const checkers = CheckersGame.create('turkish');
checkers.getLegalMoves();          // [{ from: '2|0', path: ['3|0'], captured: [] }, ...]

const match3 = new Match3Board().init();
const { from, to } = match3.getPossibleMoves()[0];
match3.swap(from, to);             // e.g. { valid: true, points: 30, steps: [...] }

Why use it

  • Rules you can trustEach game is tested against its official rules: perft for chess, FMJD and Turkish federation rules for checkers.
  • UI-agnosticPlain classes and plain data. Use any framework, or none; the examples use Preact.
  • Typed, zero dependenciesWritten in TypeScript, published as an ES module with types, no runtime dependencies.
  • Built for your own gamesThe same Board and Item core runs every game here. Start from it for a new one.
