ymir-js

A TypeScript toolkit for board games. Checkers, chess, Go and match-3 come with their full rules, built on a small board core you can use for your own games.

A taste of the API

import { ChessGame, GoGame, CheckersGame, Match3Board } from 'ymir-js';

const chess = new ChessGame();
chess.move('e4');
chess.getBestMove({ depth: 3 });   // e.g. { san: 'Nf6', from: 'g8', to: 'f6', ... }

const go = new GoGame({ size: 9 });
go.play('4|4');
go.getStatus();                    // { state: 'playing' }

const checkers = CheckersGame.create('turkish');
checkers.getLegalMoves();          // [{ from: '2|0', path: ['3|0'], captured: [] }, ...]

const match3 = new Match3Board().init();
const { from, to } = match3.getPossibleMoves()[0];
match3.swap(from, to);             // e.g. { valid: true, points: 30, steps: [...] }

Why use it

  • Rules you can trustEach game is tested against its official rules: perft for chess, FMJD and Turkish federation rules for checkers.
  • UI-agnosticPlain classes and plain data. Use any framework, or none; the examples use Preact.
  • Typed, zero dependenciesWritten in TypeScript, published as an ES module with types, no runtime dependencies.
  • Built for your own gamesThe same Board and Item core runs every game here. Start from it for a new one.

A prompt to start from

Use the ymir-js library (npm install ymir-js) for the board and the rules.
Before writing code, read https://aykutkardas.github.io/ymir-js/llms.txt,
and https://aykutkardas.github.io/ymir-js/llms-full.txt for exact types.
Coordinates are "row|col" strings. Use the built-in game classes
(CheckersGame, ChessGame, GoGame, Match3Board) when they fit; for a new
game, build on Board and Item from the core, as the custom games do.

Good to know

  • CoordinatesStrings "row|col", zero-based, row 0 at the top. Chess also takes "e4".
  • Validated movesplay / move throw on illegal moves; ask getLegalMoves() first.
  • StateGames report getStatus() and save with toJSON() / fromJSON().
  • Packagesymir-js re-exports @ymir-js/core, checkers, chess, go and match3.
